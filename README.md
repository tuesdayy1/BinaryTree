# BinaryTree

A templated binary search tree (BST) implementation in C++, built with custom Stack and Queue.

# Project structure
BinaryTree-main/
* `BinarySearchTree.h`     the BST itself
* `Stack.h`                linked-list stack, used for iterative traversal/search
* `Queue.h`                abstract queue interface
* `QueueList.h`            linked-list queue implementation (for level-order walk)
* `QueueExceptions.h`      Queue exception
* `StackUnderFlowr.h`      Stack exception
* `main.cpp`               Demo/test driver
